# 📊 Stock Market Analysis Using PostgreSQL and Streamlit

## 📌 Project Overview

This project analyzes historical stock market data of six Indian companies using PostgreSQL, SQL, Python, and Streamlit. The main objective is to understand stock price movements, trading activity, volatility, and company performance through SQL queries and interactive visualizations.

The analysis results are presented through a Streamlit dashboard and a project insights presentation.

## 🎯 Project Objectives

* Analyze historical stock prices across six companies.
* Identify the highest and lowest closing prices.
* Calculate average closing prices and percentage changes.
* Analyze positive and negative trading days.
* Identify simple BUY, SELL, and HOLD signals based on opening and closing prices.
* Examine year-wise price trends and trading volumes.
* Measure daily price volatility.
* Compare the performance of all six companies.

## 📈 Key Analysis

### 1. Data Validation

* Verify the number of records in each dataset.
* Identify the date range for each company.
* Check for duplicate dates.
* Check for NULL values in important columns.

### 2. Stock Price Analysis

* Find the highest closing price.
* Find the lowest closing price.
* Retrieve closing prices for selected dates.
* Calculate percentage changes between selected dates.
* Calculate average closing prices.

### 3. Trading Activity Analysis

* Count positive, negative, and unchanged trading days.
* Identify days with the highest trading volume.
* Analyze trading activity using the number of shares and trades.

### 4. BUY, SELL, and HOLD Signals

Simple rule-based signals are generated by comparing opening and closing prices:

* **BUY:** Closing price is higher than opening price.
* **SELL:** Closing price is lower than opening price.
* **HOLD:** Closing price equals opening price.

These are educational analytical signals based on daily price movements, not financial advice or guaranteed trading recommendations.

### 5. Trend Analysis

* Compare the current closing price with the previous trading day's closing price.
* Classify price movement as UP, DOWN, or UNCHANGED.
* Analyze year-wise average closing prices.

### 6. Volatility Analysis

* Calculate the average daily high-low price range.
* Identify the maximum and minimum daily price ranges.
* Use daily price ranges to understand historical price fluctuations.

### 7. Company Comparison

Compare all six companies based on:

* Available date range
* Average closing price
* Highest closing price
* Lowest closing price

Closing prices are compared in their respective market price units. Differences in share prices alone do not indicate which company performed better.

## 🚀 How to Run the Project Locally

### Step 1: Clone the Repository

```bash
git clone https://github.com/rachapallirajeswari12/stock-market-analysis.git
cd stock-market-analysis
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 3: Set Up PostgreSQL

1. Install PostgreSQL and open pgAdmin.
2. Create a database for the project.
3. Execute the SQL table creation statements from `stock_market_analysis.sql`.
4. Import the corresponding CSV datasets into their respective tables.
5. Configure the database connection securely in the application.

### Step 4: Configure Database Credentials

Use environment variables or Streamlit Secrets to store the database host, database name, username, and password. Do not hardcode passwords or upload credentials to GitHub.

For Streamlit Cloud, configure the required secrets and use a remotely accessible PostgreSQL database. A local database running on your computer will not automatically be accessible from the deployed application.

### Step 5: Run the Streamlit Application

```bash
streamlit run app.py
```

The application will open in your local browser.
